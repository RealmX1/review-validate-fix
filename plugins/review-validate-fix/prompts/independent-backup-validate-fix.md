# 独立备用路线：先验证再修复

你执行 `validate_fix`，只接收去来源的问题、范围／归属说明、代码、复现线索和必要标准。不要索取 reviewer 来源或重做完整双评审。

先独立验证问题是否成立。属实且属于已授权范围时实施必要修复，保存实际补丁、应用位置及修前／修后验证；误报说明可复核理由；范围外问题只验证留档。必要范围扩展明确记录，背景／protected WIP 的修改须先核对归属与并发变化，不能清理其他工作。

在主执行者指定的隔离工作区运行；工具故障时可以直接保存原始 Markdown、patch 和命令日志，不等待正常 attempt writer／cache 恢复。每条问题的事实结论与机器登记状态分开。真实失败保持失败，request 保持未完成。只有人独有的信息、新权限或实质价值取舍才升级；先完成其他独立问题。

不要擅自提交、同步、部署、生成 handoff 或输出 `RVF_HANDOFF_FILE`。返回实际结果路径，由主执行者核对后应用与最终验证。
