# RVF 固定任务快照工作流重构

来源：cdd62 中用户批准的「RVF 工作流解耦、Prompt 精简与 GitHub Issue 收集」实施计划。交付范围为本仓库 RVF 核心；Cline Kanban 配套位于任务 a289f，base-branch-sync 配套位于 my-ai-setup/58298。跨仓库工作不被记作本仓库已完成的代码或部署。

## 实现

新运行核心位于 `core/task_snapshot_review/`。独立 index 固定基线及显式任务路径，两路 reviewer 在各自工作树、新进程中检查同一候选；来源匿名的合并 findings 交一个独立 fixer。主会话核对补丁、运行最终验证并使用普通 Git 提交。进度、原始输出、固定 Git 对象及补写报告使用持久目录。

原生 OS 文件锁覆盖进程启动、Git 准备与实际子进程，不使用 tracker lease。父进程崩溃时保留已启动的角色进程；明确停止会取消其所拥有的执行。已完成的腿不重复派发，缺失腿可补证接续并保留此前发现。确定性格式故障直接换配置，瞬时故障最多原路重试一次。

已移除旧 session/hunk 归属、token、tracker、逐 issue attempt、原生回退、自动收尾再投递、独立 rvf-land/reopen/handoff-intake、备用路线及自动 Analyze/正式归档门禁，包括分发入口、调用方、专用测试和角色手册。Git 历史与任务原始输出仍用于历史核查，不作为新候选资格或成功事实。

复用了 dd4fa 中已验证的 CLI 投递、结构化输出和模型选择实现及缺腿接续思想，移除了其旧 tracker/ledger 调度依赖。保留并通过 20 项跨 CLI 结果提取测试；没有合并或修改 dd4fa 的活跃工作树。

## 输入精简统计

同一份小型任务的真实拼装器回放：旧 reviewer 初始 prompt 11,860 字符，新版 1,040 字符，减少 91.23%。分发中的全部 Agent Markdown 从 164,631 降至 6,975 字符，减少 95.76%。

当前常规角色说明：主 skill 1,429、reviewer 714、fixer 523、按需 Analyze 411、部署 skill 885 字符。需求、范围、diff 与 findings 各有单份材料，不增加运行时长度门禁。

统计不包含宿主系统提示、工具展开或模型实际 token，不将零模型成本的输入回放当作真实评审。旧版通过原始版本的 `--dry-run`，新版通过当前角色拼装器生成真实 prompt 文件；原始结果及统计保存于本任务持久交接目录。

## 问题收集与验证

GitHub 同根因问题使用一个 Issue，新 observation 追加评论；同时查询开放与关闭问题，旧人工 Issue 可以显式绑定。原始报告、写入意图及未知结果保留，重试先对账；网络/认证故障不阻断评审、提交或同步。后续 CLI 活动会按持久恢复时间异步补写，也可由宿主通用任务执行 flush。

自动化覆盖双审、匿名修复、真实红测、格式故障与替代 CLI、任务已提交后评审、提交后登记中断、基线漂移、staged/unstaged/untracked WIP、二进制与符号链接、进程启动窗口中断、明确停止、缺腿补证、凭据不落运行材料，以及 GitHub 关闭匹配、同 observation 重试、并发、未知写入、TLS 替代和断网恢复。最终运行次数及结论以本任务原始验收输出为准。

安装验收另发现：打包器原本先沿 state 符号链接复制历史运行数据，再删除目标 state。现改为复制入口排除，避免运行历史放大安装成本；该已复现问题已保存为 GitHub observation，认证可用后自动补写。

当前实现未要求部署或 base handback。源码提交、跨仓库整合、push 和本机安装分别核对与报告。
